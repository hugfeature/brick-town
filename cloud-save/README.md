# 历史云端实现（当前前端已停用）

2026-10-02 起，GitHub Pages 宠物页面使用本机存档，不再连接这里的云端接口。以下内容仅记录旧版实现。旧数据未删除，也不会自动迁入本机版。

# 团团云端存档

网页在 `pet/`，云端接口为 `/api/pet`。GitHub Pages 只托管前端，数据库不会写入 GitHub 仓库。生产云端由 ChatGPT Sites 的 Cloudflare Worker + D1 提供，`worker.mjs` 为可迁移的核心接口。

同一家庭链接的 URL fragment 中携带 192 位随机钥匙；服务端只存钥匙的 SHA-256，不提供枚举小窝的接口。钥匙通过 Authorization 请求头传输，不放进请求 URL。知道家庭链接的人可以读写这个小窝，请只发给家人。丢失链接且所有设备都清除了网站数据后，无法找回原小窝；页面提供复制链接功能。

接口使用 revision 条件更新防止两台设备互相覆盖；requestId 处理最后一笔请求的重复提交。网络错误时客户端不宣称保存成功，不静默新建小窝，不把本地快照覆盖到云端。离线会停用修改，连接恢复后重新读取。每 15 秒、切回前台和操作前的版本冲突都会同步。

迁移到自有 Cloudflare Worker：绑定 D1 为 `DB`，按 `schema.sql` 创建表，把 `state.mjs` 与 Worker 一同部署，修改 Worker 允许的来源域名及前端 `API_URL`。不需要也不应向前端填入 GitHub token、数据库密钥或 Cloudflare 管理凭据。

## 家长奖励与互动兑换（试行）

`pet/rules.mjs` 和服务端 `rules.mjs` 集中定义任务奖励及互动价格。默认作业 +20、阅读打卡 +10、习惯打卡 +5；每项每天由家长确认一次（北京时间），另支持家长填写原因奖励 1～500 分。互动不产生积分。喂食 5、洗澡 8、找颜色 10、数星星 10、翻牌 12、跳舞 6；摸摸、睡觉、叫醒、改名免费。

首次由家长设置六位数字密码后才能发积分。服务器校验 PBKDF2-SHA256（100000 次、随机 salt），校验值只保留在云端存档的私有 `_parent` 字段，所有 API 响应都通过白名单去除它。连续五次失败锁定十分钟；不在浏览器存储密码。家庭链接的首位使用者可以设置密码，因此请家长先设置再分享给孩子；暂未提供密码找回。

积分、家长发分、任务确认、余额和最近 12 条流水都由服务端计算，沿用同一个 revision 条件写入与请求去重，客户端传入余额无效。新规则兼容原宠物存档（原状态保留、积分从零开始）。游戏与洗澡确认兑换时扣分并应用宠物状态，结束不再扣分；退出可通过“继续”恢复已兑换互动，不会重复扣分；这份兑换资格也保存到云端，完成后清除。网络不确定时只重试同一笔请求。自定义奖励每次都是新的家长确认，固定任务不能重复领取。

发布时同时更新 `state.mjs`、`rules.mjs` 和 `worker.mjs`；无需修改现有数据库表。

## 手机连接恢复

连接失败面板位于宠物状态条上方，直接提供重连、输入完整家庭链接或 48 位家庭口令、带同一家庭 fragment 的独立页面入口。未确认的保存操作存在时隐藏独立页面入口，先用原 requestId 重试确认，避免导航丢失未决操作。切回前台也会重连。链接/口令解析不访问其他域名，家庭钥匙不会放入查询参数。页面区分离线、超时、存档不存在、网络不可达；不把连接失败显示成进度归零。
