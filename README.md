# 积木小镇 · 兜风赛车

免费、无广告的手机网页赛车，面向约 5–7 岁孩子与家长一起玩。小车自动前进，按住左右大按钮转向，松开后保持横向位置；桌面支持方向键和 A/D。

线上地址：https://hugfeature.github.io/brick-town/

## 小熊的野餐

默认进入送苹果任务：看图或点击“听小熊说一遍”，收集三个红苹果并送到终点。途中按实物显示 1/3、2/3、3/3；碰撞不丢苹果。没找齐时可带着已有苹果继续走果园小路。

送达后从小熊徽章、彩虹尾翼、星星车灯中自选一件，立即装在车上，并保存在当前浏览器的车库中。可以以后再选，刷新后仍能领取。装饰只改变外观，不提升速度；不设连续签到或限时奖励。自由兜风模式仍可随时在出发前选择。

出发讲解使用内置的中文合成音频，点击直接播放，不依赖系统朗读引擎或外部语音接口；可再次点击停止，静音、开始或离开页面会停止讲解。行驶中的动态短句仅在系统语音可用时朗读，同时始终显示图文提示。任务提供数数、观察目标和完成帮助行为的练习机会，不保证具体学习效果。

## 玩法

- 森林、海岸、落日三条赛道，全部开放。每局约 25–45 秒，不设倒计时催促。
- 两种驾驶速度（30 / 39 游戏米每秒）、四种车身颜色；收集星星、避开路锥与前车，到达终点。
- 碰撞只会短暂减速，不扣生命；左右转向设有道路内的保护边界，长按也不会把赛车开到草地上。
- 暂停键或空格暂停。失去焦点、切到后台会暂停，并清除按键状态；回到游戏后手动继续。
- 声音默认关闭，可手动开启引擎声和拾取提示音。
- 任务模式、装饰、待选礼物、赛道、车色和最佳星数保存在当前浏览器 `brickTownRacerV1` 中，不上传。旧版搭桥存档保留，不混用。

## 运行与验证

赛车版本为 `index.html`，Canvas 2D + 原生 JavaScript，无外部字体、图片、网络接口或运行依赖。GitHub Pages 直接托管，无须构建。浏览器需要 Canvas 2D 和 Pointer Events 支持；不依赖较新的 roundRect 绘图接口，缺少 ResizeObserver 时使用窗口尺寸事件。

自动化回归：

```sh
npm install
npx playwright install chromium
npm test
```

可通过 `TEST_BROWSER_PATH` 指定已安装的 Chromium。启动测试使用真实时钟，覆盖标准浏览器、缺少 roundRect / ResizeObserver 的兼容场景与低帧率场景，验证倒计时结束后车辆确实前进。其余测试启动临时本地 HTTP 服务，使用真实浏览器验证手机布局、触屏左右控制与松手、键盘控制、暂停恢复、切后台保护、三条赛道通关、碰撞与收集、重新开始、存档恢复。测试只接管动画时钟，不在生产页面中暴露修改游戏状态的接口。

## 陪玩建议与边界

先选“轻松兜风”，让孩子尝试左、右与松手，观察前方障碍后再转向。游戏提供方向对应和提前观察的练习机会，不代表已经测量或保证能力提升。小车转向和速度是简化的游戏规则，不模拟真实驾驶。

手机竖屏优先；很矮的横屏窗口允许滚动，建议转回竖屏。清除网站数据会丢失成绩；存储不可用时仍可玩。不同手机的音频解锁行为可能有差异。

## 手机流畅度

行驶模拟使用 60 Hz 小步长累积真实时间，渲染帧率低时不会按每帧 45ms 截断时间；单次超过 250ms 的长停顿仍限制补算，防止突发长卡顿后失控。切后台仍暂停。

仪表最多每 100ms 刷新且只更新变更文字，画布像素倍率上限为 1.25，移除游戏中的背景模糊，并复用道路分段投影、减少远景树木。道路色带使用世界坐标，随车连续移动。

`tests/timing.cjs` 对 5 / 15 / 60 FPS 使用受控帧时钟验证等时行驶距离、HUD 修改数量和高像素密度手机的画布大小；它验证低帧率下的正确性和工作量，不宣称某台实体手机达到固定帧率。

`tests/picnic.cjs` 验证送达领奖、漏苹果后继续、礼物暂存与恢复、装饰保存和锁定、旧存档兼容、语音不可用回退及切换自由兜风。

## 手机视口验收

手机页面按实际可视高度布局，同时监听窗口与 VisualViewport 的尺寸变化；不依赖动态视口 CSS 单位支持。画布使用明确的像素尺寸，仪表和任务条占独立空间，避免遮挡赛车。小于 480px 的极矮窗口保留最小可操作高度并允许滚动。

`tests/viewport.cjs` 在 320–390px 宽、500–844px 高、运行中收缩/放大视口和缺少 ResizeObserver 的情况下，检查提示与道路不重叠、画布铺到底、绘图尺寸同步、方向键可见及任务/自由模式切换。发布前同时人工审视开始、驾驶、领奖和车库的渲染截图，不能只以功能测试通过作为验收。

赛车外观采用尖车鼻、开放座舱、四个外露轮胎及前后翼，车库预览同步。`tests/racer.cjs` 禁用系统语音接口后验证内置音频实际解码、播放、停止和静音；同时检查三条赛道、三种视口高度下左右极限位置的轮胎像素都在沥青路面内。


## 团团的小窝 · 电子宠物

入口：https://hugfeature.github.io/brick-town/pet/ 。原赛车不变，右上角增加小狐狸入口。

适合约 5–7 岁孩子：喂食、戳五个泡泡洗澡、三轮找颜色、睡觉恢复精神、摸摸和改名字。没有广告、签到、扣命或离线衰减；可以随时休息。音效默认关闭，无语音依赖。

第一次点击“领养团团”，在当前设备、当前浏览器创建自己的小窝。宠物、积分、家长密码校验值和已兑换互动自动保存在浏览器 `brickTownPetLocalV1` 中。刷新或关闭后再次打开同一浏览器可继续；其他手机、其他浏览器各自拥有独立进度。普通链接可直接发给朋友，不包含任何人的存档。

网页、图片、脚本全部由 GitHub Pages 同站点提供，游戏不再请求 `chatgpt.site` 或其他存档服务。页面完整加载后，短暂断网也能操作和保存；重新加载页面仍需要能访问 GitHub Pages，不宣称未缓存页面可离线启动，也不保证所有网络都能访问 GitHub。

“备份 / 换手机”可复制 `FOX1.` 存档码或下载文本文件；在另一设备“导入存档”中粘贴完整内容，预览后确认导入。已有小窝须勾选替换，设置了家长密码的还须输入当前小窝密码。导入保留备份中的家长密码，之后两台设备各自保存，不自动同步。替换前的原始存档另存于 `brickTownPetLocalV1Previous`。清除网站数据、无痕窗口关闭或浏览器回收网站数据可能丢失本机进度，请自行保留备份。

写入成功后才更新界面；写入失败会保留原积分并显示错误。损坏存档不会静默重建，可用有效备份恢复。多标签页使用 Web Locks（可用时）和写入前版本校验；过期页面不得直接覆盖更新后的状态。家长密码是本机防误操作措施，不构成服务端防篡改能力。

原 `cloud-save/` 接口与已部署的旧云端数据保留作历史实现；新页面不读取或删除它们。旧家庭链接会打开本机版，不自动迁移旧云端进度。

`pet/` 是无需构建的静态前端。宠物验证运行 `npm run test:pet`，覆盖本机持久化、设备隔离、积分、密码、备份导入、保存失败、冲突、断网游玩和无外部请求。`tests/pet-cloud.cjs` 仅用于旧云端接口回归。

### 电子宠物积分（家长确认版）

家长先在“家长确认 / 发积分”中设置六位密码。孩子完成现实中的作业或打卡后，由家长确认发分，再用积分兑换喂食、洗澡及小游戏。默认值集中在 `pet/rules.mjs`，具体规则可后续调整；支持家长临时自定义奖励。互动不会赚取积分，摸摸和睡觉免费。密码、积分和任务记录均只属于当前浏览器的小窝。
