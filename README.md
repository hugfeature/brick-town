# 积木小镇 · 兜风赛车

免费、无广告的手机网页赛车，面向约 5–7 岁孩子与家长一起玩。小车自动前进，按住左右大按钮转向，松开后保持横向位置；桌面支持方向键和 A/D。

线上地址：https://hugfeature.github.io/brick-town/

## 小熊的野餐

默认进入送苹果任务：看图或点击“听小熊说一遍”，收集三个红苹果并送到终点。途中按实物显示 1/3、2/3、3/3；碰撞不丢苹果。没找齐时可带着已有苹果继续走果园小路。

送达后从小熊徽章、彩虹尾翼、星星车灯中自选一件，立即装在车上，并保存在当前浏览器的车库中。可以以后再选，刷新后仍能领取。装饰只改变外观，不提升速度；不设连续签到或限时奖励。自由兜风模式仍可随时在出发前选择。

语音使用浏览器提供的中文语音能力；不可用时保留完整图文提示。任务提供数数、观察目标和完成帮助行为的练习机会，不保证具体学习效果。

## 玩法

- 森林、海岸、落日三条赛道，全部开放。每局约 25–45 秒，不设倒计时催促。
- 两种驾驶速度（30 / 39 游戏米每秒）、四种车身颜色；收集星星、避开路锥与前车，到达终点。
- 碰撞只会短暂减速，不扣生命；开到路边也会减速，回到路上恢复。
- 暂停键或空格暂停。失去焦点、切到后台会暂停，并清除按键状态；回到游戏后手动继续。
- 声音默认关闭，可手动开启引擎声和拾取提示音。
- 任务模式、装饰、待选礼物、赛道、车色和最佳星数保存在当前浏览器 `brickTownRacerV1` 中，不上传。旧版搭桥存档保留，不混用。

## 运行与验证

生产版本只有 `index.html`，Canvas 2D + 原生 JavaScript，无外部字体、图片、网络接口或运行依赖。GitHub Pages 直接托管，无须构建。浏览器需要 Canvas 2D 和 Pointer Events 支持；不依赖较新的 roundRect 绘图接口，缺少 ResizeObserver 时使用窗口尺寸事件。

自动化回归：

```sh
npm install
npx playwright install chromium
npm test
```

可通过 `TEST_BROWSER_PATH` 指定已安装的 Chromium。启动测试使用真实时钟，覆盖标准浏览器、缺少 roundRect / ResizeObserver 的兼容场景与低帧率场景，验证倒计时结束后车辆确实前进。其余测试启动临时本地 HTTP 服务，使用真实浏览器验证手机布局、触屏左右控制与松手、键盘控制、暂停恢复、切后台保护、三条赛道通关、碰撞与收集、重新开始、存档恢复。测试只接管动画时钟，不在生产页面中暴露修改游戏状态的接口。

## 陪玩建议与边界

先选“轻松兜风”，让孩子尝试左、右与松手，观察前方障碍后再转向。游戏提供方向对应和提前观察的练习机会，不代表已经测量或保证能力提升。小车转向和速度是简化的游戏规则，不模拟真实驾驶。

手机竖屏优先；很矮的横屏窗口允许滚动，建议转回竖屏。清除网站数据会丢失成绩；存储不可用时仍可玩。不同手机的音频解锁行为可能有差异。

## 手机流畅度

行驶模拟使用 60 Hz 小步长累积真实时间，渲染帧率低时不会按每帧 45ms 截断时间；单次超过 250ms 的长停顿仍限制补算，防止突发长卡顿后失控。切后台仍暂停。

仪表最多每 100ms 刷新且只更新变更文字，画布像素倍率上限为 1.25，移除游戏中的背景模糊，并复用道路分段投影、减少远景树木。道路色带使用世界坐标，随车连续移动。

`tests/timing.cjs` 对 5 / 15 / 60 FPS 使用受控帧时钟验证等时行驶距离、HUD 修改数量和高像素密度手机的画布大小；它验证低帧率下的正确性和工作量，不宣称某台实体手机达到固定帧率。

`tests/picnic.cjs` 验证送达领奖、漏苹果后继续、礼物暂存与恢复、装饰保存和锁定、旧存档兼容、语音不可用回退及切换自由兜风。
