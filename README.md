# 积木小镇 · 小小工程师

面向约 5–7 岁孩子的中文网页小游戏：观察桥面缺口，组合不同长度的积木，试车并修正，再按数量送货。另有 8×5 自由积木画板。

## 使用

直接打开 `index.html`，或通过 GitHub Pages 托管；不需要构建、账号、后端或第三方资源。手机和电脑均可点选操作。中文朗读取决于浏览器的 SpeechSynthesis 支持，首次需要点击语音按钮。

六个任务均开放，可在“小镇”中重玩；完成任务与自由作品保存到当前浏览器的 `brickTownV2` localStorage。未完成任务重新进入时重置桥面和装货。旧版存档保留，但不迁移为新版成就。存储不可用时仍可玩，但无法跨刷新保存。

## 设计边界

- 不自动指出所有答案；提示逐步提供，允许先试车再改。
- 桥面是离散格子的组合规则，不是物理受力模拟。
- 没有倒计时、连续签到、广告、付费或个人信息收集。
- 这是练习空间组合、数量对应和修改策略的游戏，不是认知测评工具，也不保证教育效果。
- 推荐成人陪同开始，一次 1–2 关，之后可用真实积木重现。

## 手工验收

1. 桥未接好时出发：车停在第一个缺口前，并提示补桥。
2. 桥接好但货量不对：提示缺少或多出的数量，不计完成。
3. 所有任务都可通关；第四关的中间陆地不能被积木跨占。
4. 拆回积木会归还库存；没有库存的积木不可继续选择。
5. 刷新后完成记录和自由作品保留；损坏的存档不会阻止启动。
6. 390px 宽手机页面无横向溢出；弹窗支持 Escape 和键盘焦点循环。
