# 积木小镇 · 兜风赛车

免费、无广告的手机网页赛车，面向约 5–7 岁孩子与家长一起玩。小车自动前进，按住左右大按钮转向，松开后保持横向位置；桌面支持方向键和 A/D。

线上地址：https://hugfeature.github.io/brick-town/

## 玩法

- 森林、海岸、落日三条赛道，全部开放。每局约一分钟，不设倒计时催促。
- 两种驾驶速度、四种车身颜色；收集星星、避开路锥与前车，到达终点。
- 碰撞只会短暂减速，不扣生命；开到路边也会减速，回到路上恢复。
- 暂停键或空格暂停。失去焦点、切到后台会暂停，并清除按键状态；回到游戏后手动继续。
- 声音默认关闭，可手动开启引擎声和拾取提示音。
- 赛道、车色和最佳星数保存在当前浏览器 `brickTownRacerV1` 中，不上传。旧版搭桥存档保留，不混用。

## 运行与验证

生产版本只有 `index.html`，Canvas 2D + 原生 JavaScript，无外部字体、图片、网络接口或运行依赖。GitHub Pages 直接托管，无须构建。浏览器需要 Canvas 2D、Pointer Events 和 ResizeObserver 支持。

自动化回归：

```sh
npm install
npx playwright install chromium
npm test
```

可通过 `TEST_BROWSER_PATH` 指定已安装的 Chromium。测试启动临时本地 HTTP 服务，使用真实浏览器验证手机布局、触屏左右控制与松手、键盘控制、暂停恢复、切后台保护、三条赛道通关、碰撞与收集、重新开始、存档恢复。测试只接管动画时钟，不在生产页面中暴露修改游戏状态的接口。

## 陪玩建议与边界

先选“轻松兜风”，让孩子尝试左、右与松手，观察前方障碍后再转向。游戏提供方向对应和提前观察的练习机会，不代表已经测量或保证能力提升。小车转向和速度是简化的游戏规则，不模拟真实驾驶。

手机竖屏优先；很矮的横屏窗口允许滚动，建议转回竖屏。清除网站数据会丢失成绩；存储不可用时仍可玩。不同手机的音频解锁行为可能有差异。
